## 2024-08-24 - React Component Remount API Throttling
**Learning:** Found that multiple dashboard components (AdvisoryDashboard, MarketDashboard, SustainabilityDashboard, FieldIntelligence) invoke expensive AI and external API calls directly inside `useEffect` blocks that run on every mount without any module-level caching. Because the primary navigation (SidebarNav) works by unmounting and remounting these component tabs, navigating between tabs rapidly drains API quotas and delays UI rendering with redundant network requests.
**Action:** Implement a module-level Promise cache mechanism outside the React component scope to intercept and memoize the API responses for static or semi-static calls across remounts, ensuring user-triggered manual refresh buttons bypass the cache.
