## 2024-05-24 - React.memo and useCallback for Dashboard Layout Components
**Learning:** The application's dashboard architecture relies heavily on global layout state (e.g., `activeTab`, `currentLocation`). To prevent unnecessary re-renders on unrelated layout state changes, we must wrap heavy data-fetching child components (and layout components like `SidebarNav` and `TopNav`) in `React.memo` and ensure the parent component (`Dashboard` in `src/app/page.tsx`) uses `useCallback` for any function props to maintain stable references, as inline functions negate `React.memo`.
**Action:** Always verify if parent components are passing inline functions as props to child layout or data-heavy components, and memoize them along with `React.memo` where appropriate to optimize render performance.
