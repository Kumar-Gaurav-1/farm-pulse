## 2025-02-23 - Module-level Cache for AI Feature API Calls in Next.js Tab Structures
**Learning:** In frontend architectures where tabs or route changes frequently remount components, initiating expensive network requests (like Genkit AI synthesis calls) inside `useEffect` on every mount creates significant redundant load and performance bottlenecks.
**Action:** Implemented a lightweight module-level Promise cache outside the React component scope. This stores the active fetch promise and re-uses it across component remounts, preventing redundant calls while still allowing the component to react to the resolved data. Ensured error cases reset the cache to `null` so failures aren't permanently cached, and provided manual override flags (`forceRefresh`) for user-initiated syncs.
