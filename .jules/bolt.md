## 2025-02-18 - Lazy Load Hidden React Components in Next.js
**Learning:** In Next.js applications, conditionally rendered components (like tabs that are initially hidden) add significantly to the initial JavaScript payload (First Load JS) if they are statically imported. The `src/app/page.tsx` file had multiple large tab components imported statically, resulting in a 284 kB First Load JS for the `/` route.
**Action:** When working with Next.js SPAs that have heavy conditionally rendered content (like complex tabs or dashboard views), always use `next/dynamic` to lazy-load components that are not visible on the initial render. This optimization reduced the First Load JS for the root page from 284 kB down to 162 kB (a ~43% reduction). Be sure to keep default visible components (like `AdvisoryDashboard` in the overview) statically imported to prevent loading layout flashes.
