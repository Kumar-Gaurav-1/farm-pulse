## 2024-08-07 - React.memo Optimization for App Layout\n**Learning:** The application uses a global layout state (`activeTab`, `currentLocation`) in `src/app/page.tsx` which causes unnecessary re-renders of the heavy dashboard components like `TopNav`, `SidebarNav`, and complex features (`AdvisoryDashboard`, `MarketDashboard`, etc.) when any state changes.\n**Action:** Use `React.memo` to wrap layout components like `TopNav` and `SidebarNav`. Ensure `useCallback` is used for function props in the parent to maintain stable references, preventing them from negating the `React.memo` optimizations.
