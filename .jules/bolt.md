## 2026-08-11 - [Optimize FieldHealth rendering]
**Learning:** Component `FieldHealth` lacks memoization. The parent `Dashboard` component triggers frequent re-renders due to unrelated state changes (like `activeTab`, `formattedDate`). Because `FieldHealth` receives an inline callback `onDiagnose={(id) => setIsDiagnosing(id)}`, applying `React.memo` would be ineffective as the prop identity changes every render. Passing the stable state setter `setIsDiagnosing` directly prevents re-creating the function on every render, allowing `React.memo` to work correctly.
**Action:** Always wrap heavy presentation components in `React.memo` and leverage the native stable identities of React state setters (like `setIsDiagnosing`) instead of creating inline wrappers `(id) => setIsDiagnosing(id)`.
