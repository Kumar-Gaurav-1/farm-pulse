## 2024-05-18 - [React Mount-Level Caching for API Requests]
**Learning:** Components in the dashboard (like MarketDashboard, AdvisoryDashboard, SustainabilityDashboard) are unmounted and remounted frequently when switching tabs in `src/app/page.tsx` since the router uses a conditional render instead of hiding DOM elements. Because each component fetches expensive AI API flows natively on mount without state preservation or caching, changing tabs causes redundant, slow, and expensive API requests.
**Action:** Implement module-level Promise caching (outside component scope) for these dashboard modules. When a component mounts, it should first check the cache. If a request is already resolved or in-flight, it uses that Promise. This prevents redundant API requests when a user rapidly switches tabs, while retaining the ability to force a refresh on explicit user action (e.g. clicking 'Sync Streams').
