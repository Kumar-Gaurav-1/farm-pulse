## 2025-02-12 - Prevent Re-renders with React.memo and useCallback
**Learning:** The dashboard heavily relies on complex data visualizations and fetching logic. `TopNav` forces `page.tsx` re-renders and children to re-render without need. Wrapping heavy data-fetching or static child components with `React.memo` combined with using `useCallback` for their function props in `page.tsx` prevents unnecessary re-renders when layout states change. Note that inline functions in parents bypass `React.memo` unless they are wrapped in `useCallback` or unless we only use stable references like state setters natively.
**Action:** Use `React.memo` for complex child components in dashboard architectures and apply `useCallback` to their function props if passed from a parent that re-renders frequently.
