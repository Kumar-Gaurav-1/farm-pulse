## 2024-07-22 - Missing Memoization in SidebarNav Component
**Learning:** In a highly interactive Next.js application where the parent component (`src/app/page.tsx`) holds state (`activeTab`) and passes it down, child components that don't depend on every state change should be memoized to prevent unnecessary re-renders. The `SidebarNav` component is currently re-rendering every time `activeTab` or other layout state changes. The `onTabChange` prop in `page.tsx` is being passed an inline arrow function, which breaks `React.memo` unless `useCallback` is used.
**Action:** Wrap layout components like `SidebarNav` and `TopNav` in `React.memo()` and wrap the callback functions passed as props (e.g., `onTabChange`, `onLocationChange`) with `useCallback` to maintain referential equality and prevent expensive, unnecessary re-renders of the entire sidebar navigation.
