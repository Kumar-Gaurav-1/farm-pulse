## 2024-08-06 - Initial Profile
**Learning:** Found Next.js app with `SidebarNav` and multiple heavy dashboard components (`FieldHealth`, `AdvisoryDashboard`) rendered based on `activeTab` state in `src/app/page.tsx`. `SidebarNav` and `FieldHealth` receive inline functions (`onTabChange` and `onDiagnose`), which will cause them to re-render unnecessarily on every state change in `page.tsx` (e.g. `currentLocation` or even just itself) unless wrapped in `React.memo` and passed stable references (via `useCallback` or direct state setters if applicable). However, in React, state setters themselves have stable identities. For `setIsDiagnosing(id)`, we can just pass `setIsDiagnosing` directly.
**Action:** Extract inline functions to `useCallback` or pass stable setters, and use `React.memo` on heavy child components to prevent unnecessary re-renders.
